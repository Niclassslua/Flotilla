# Test value inventory

Source audit of commit `6461b54`, 2026-09-09. See [findings](test-suite-audit.md) and [testing policy](testing.md).

All 652 declared test methods were inspected with their fixtures and assertions. The 82 file rows below account for every method; the exception table names every non-Keep disposition. **Every method not listed in the exception table is Keep**, subject to its file-level notes and the audit-wide isolation/timing limitations. These are static judgments of coverage value, not observed pass/fail or flakiness results.

- **Keep:** protects a useful current contract. This does not mean exhaustive coverage or a verified green run.
- **Strengthen:** intended contract matters, but current evidence is incomplete, masked or misleading. Retain the scenario and repair its proof.
- **Consolidate:** preserve meaningful cases while merging duplicate/projection/mock setup. This is not blanket deletion.
- **Remove:** current check offers little independent regression value; some test-local algorithms should be replaced only if real behavior coverage is missing.
- **Move:** useful artifact, diagnostic or environment-dependent workload belongs outside the ordinary regression lane.
